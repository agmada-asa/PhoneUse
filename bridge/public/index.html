PhoneUse Checking connection

Set up your phone

Follow the steps in order. Control stays off until you allow it on the phone.

  1. Install and open PhoneUse on your phone, then tap Scan pairing QR code and point it at this screen. The phone connects after you confirm the computer address.

    Keep this private. Anyone who scans it on your network can connect to this computer. Hide it when you are done.

    Pair by pasting a code instead

    Both devices must be on the same Wi-Fi network.

  2. In PhoneUse, tap Turn on next to Accessibility, then enable the PhoneUse service. PhoneUse uses it to read the screen and tap only while you allow control.

    Android says the setting is restricted

    Open Settings → Apps → PhoneUse, tap the three-dot menu, and choose Allow restricted settings. Then return to Accessibility and enable PhoneUse. The app's Setup help link opens the same page.

  3. In PhoneUse, turn on Allow this computer to control the phone. It switches off whenever the phone disconnects.

    Choose apps to protect on the phone first. PhoneUse and protected apps can never be read or controlled.

  4. Register the PhoneUse tools with Codex, then start a new session. Keep this bridge running while the agent works.

    codex mcp add phoneuse -- node {{MCP_ENTRY}}

    Other MCP hosts: run node with the same file path. Your agent may send what it reads from the phone to its model provider.
